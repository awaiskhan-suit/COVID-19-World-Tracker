# 🌍 COVID-19 World Tracker

A Flutter-based COVID-19 World Tracker application that retrieves COVID-19 statistics through a REST API and displays global and country-wise information in a clean and interactive interface.

## 🚀 Features

### 🌍 World Statistics

The application displays:

* Total Cases
* Recovered Cases
* Total Deaths
* Active Cases
* Critical Cases
* Today's Cases
* Today's Deaths
* Today's Recovered

Statistics are also visualized using an interactive ring chart.

### 🌎 Countries List

Users can:

* View countries from the API
* See country flags
* View total cases
* Search countries by name
* Filter results dynamically
* Select any country to view detailed information

### 📊 Country Details

The country detail screen provides:

* Country Name
* Country Flag
* Continent
* Total Cases
* Today's Cases
* Deaths
* Today's Deaths
* Recovered
* Today's Recovered
* Active Cases
* Critical Cases
* Tests
* Cases Per One Million
* Deaths Per One Million
* Population
* ISO2 Code
* ISO3 Code
* Latitude
* Longitude
